Taste Profile

A personal, open-source tool by Guillermo Basterra that turns my own Pinterest boards into a visual taste profile that AI assistants can consult before making design decisions.

What it does

  1. Reads my own boards and pins, read-only, through the Pinterest API.
  2. Downloads the pin images to my computer and groups them into visual styles with an image-embedding model that runs locally.
  3. Writes a short text description of each style, plus a few example thumbnails, into plain files on my computer.
  4. Lets AI coding assistants I run read those files, so their design choices match my taste.

What it does not do

  • It never creates, edits or deletes pins, boards or anything else on Pinterest.
  • It only accesses my own account. It has no other users and no sign-up.
  • It does not run a server, show ads, or sell or share data.
