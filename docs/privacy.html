Privacy Policy

Taste Profile · Last updated November 22, 2026

Taste Profile is a personal, open-source tool built and operated by Guillermo Basterra for his own use. It connects to one Pinterest account, his own. This policy explains what data the tool accesses and what happens to it.

Data accessed from Pinterest

With the account owner's authorization, the tool reads the following through the Pinterest API, using read-only permissions (boards:read, boards:read_secret, pins:read, pins:read_secret, user_accounts:read):

  • Board names and section names
  • Pin titles, descriptions, alt text, links and creation dates
  • Pin images

The tool never writes to Pinterest. It does not create, edit or delete pins or boards, and it does not access any other user's account.

Where the data is stored

Everything is stored as plain files on the account owner's own computer. There is no server and no database operated by this tool. Access tokens are stored locally in a file readable only by the owner's user account, and are never logged or shared.

Third-party services

  • Anthropic (Claude API): to write text descriptions of each visual style, the tool sends a small number of example pin images, and their board names and titles, to Anthropic's API. This data is handled under Anthropic's privacy policy and commercial terms.
  • Hugging Face: the image-embedding model is downloaded from Hugging Face and run locally. No Pinterest data is sent to Hugging Face.

No data is sold, rented, or used for advertising. This website uses no cookies, analytics or tracking.

Retention and deletion

Data is kept on the owner's computer until the owner deletes it. Deleting the tool's data folder removes it completely. Access can be revoked at any time from Pinterest's settings under Security and logins → Apps.

Contact

Questions about this policy: open an issue at github.com/guillebasterra/embedded-taste-profile/issues.
